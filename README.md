"01" — Sobre

NEXUS//01 é um pequeno jogo de adivinhação desenvolvido durante meus primeiros estudos em programação.

O projeto começou simples. A ideia era criar um jogo, testar a lógica e fazer funcionar.

Em algum momento, porém:

«"e se eu transformasse isso em um APK?"»

E foi assim que um joguinho virou meu primeiro projeto Android.
