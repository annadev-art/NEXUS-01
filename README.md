## sobre

**NEXUS//01** é um jogo de adivinhação desenvolvido como um projeto prático de programação.

A ideia era simples: criar um jogo e conseguir transformar o código em um aplicativo Android.

O resultado foi meu primeiro APK.

E sim, ele sobreviveu aos bugs, aos erros de instalação e aos builds que decidiram testar minha paciência.

---

## como nasceu

O NEXUS//01 foi criado **inteiramente pelo celular**, usando o **Termux** como ambiente de desenvolvimento.

Eu não tinha um computador para desenvolver o projeto.

Tinha um celular, algumas ideias e uma vontade muito específica de fazer aquilo funcionar.

O código foi escrito pelo celular, os arquivos foram organizados pelo Termux, os testes foram feitos ali mesmo e, depois de alguns problemas no caminho, o APK finalmente saiu.

## desenvolvimento

Durante a criação do NEXUS//01, trabalhei com:

- lógica de programação;
- criação de interface;
- HTML, CSS e JavaScript;
- estrutura de uma aplicação;
- integração com Android;
- geração de APK;
- uso do Termux como ambiente de desenvolvimento;
- Git e GitHub;
- resolução de erros durante o processo.

O projeto foi uma forma de pegar o que eu estava aprendendo e transformar em algo que pudesse realmente ser instalado e executado em um celular.
